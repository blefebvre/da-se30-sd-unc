# cards-logos

Custom **cards** block. Purpose: sponsor-logo-wall.

## Authoring (Document Authoring)

Model: `standalone`

One row per partner, two cells: `[logo image | partner link]`.
The logo becomes the link; the link text is not displayed and is used as the
accessible name (falls back to the image alt when the text is just a URL).
Rows without an image are skipped; rows without a link render an unlinked logo.

Layout: 3 equal columns at every width (336px / 720px / up to 1200px
container), square logos centered in each column.

## Supported variations

No variations.
